# Wiaam Hassan Abdo – Portfolio

Personal portfolio of Wiaam Hassan Abdo, a computer science student at the Lebanese University. Built with plain HTML, CSS, and JavaScript. No build step.

**Live site:** https://wiaamabdo2006-creator.github.io/portfolio/

## Sections
- Hero with a short intro and links to GitHub and LinkedIn
- About me
- Skills
- Featured projects (Gym Management System, POS System, Service Marketplace App) with detail popups
- Contact form and direct email

## Features
- Responsive layout with a mobile menu
- Automatic light and dark mode
- Accessible: keyboard focus styles, semantic HTML, reduced-motion support

## Run locally
Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy on GitHub Pages
1. Push this repository to GitHub.
2. Go to Settings → Pages.
3. Under "Build and deployment", choose "Deploy from a branch", then branch `main` and folder `/ (root)`.
4. Save. The site appears after about a minute.
